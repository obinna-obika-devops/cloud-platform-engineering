# Azure AKS Reference Implementation

This directory extends the flagship platform with an Azure implementation for cloud engineering, DevOps, SRE and platform-engineering scenarios.

It provisions a modular Azure foundation with Terraform: Resource Group, VNet/subnet, AKS, Azure Container Registry, Key Vault and Log Analytics. The Kubernetes examples demonstrate rolling updates, health probes, resource controls, autoscaling and disruption protection.

This is a reference implementation. It contains no credentials and does not claim a currently running production environment.
