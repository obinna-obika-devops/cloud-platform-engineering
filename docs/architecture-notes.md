# Architecture Notes

Developer change → GitHub → CI validation → Terraform / GitOps → AWS + Kubernetes → workloads → security + observability → SRE operations → feedback.

The repository uses this flow to demonstrate infrastructure-as-code, Kubernetes platform controls, GitOps, security guardrails, observability, SLO thinking, and operational feedback loops.

> Portfolio/reference architecture. No production deployment is implied.
