# Architecture Lifecycle

1. Developer creates a change.
2. GitHub provides source control and review workflow.
3. CI validates tests, infrastructure, and security.
4. Terraform and GitOps reconcile declared platform state.
5. AWS/Kubernetes hosts workloads.
6. Security and observability provide guardrails and signals.
7. SRE practices turn signals into operational decisions.
8. Incidents and improvements feed the next engineering change.
