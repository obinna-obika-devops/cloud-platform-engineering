# LinkedIn Featured Project

## Title
Production Cloud Platform Engineering | DevOps • SRE • Platform • Cloud

## Description
Designed a production-style cloud platform that demonstrates end-to-end DevOps, Site Reliability Engineering, Platform Engineering and Cloud Engineering practices across AWS and Azure patterns. The project uses Terraform, Kubernetes, Docker, GitHub Actions and GitOps, with reusable infrastructure modules, workload identity, policy-as-code, automated validation, security scanning, observability, autoscaling, SLOs, incident runbooks and disaster-recovery practices.

## Skills represented
DevOps • SRE • Platform Engineering • Cloud Engineering • AWS • Azure • EKS • AKS • Terraform • Kubernetes • Docker • GitHub Actions • Argo CD • Helm • Prometheus • IAM/RBAC • Infrastructure as Code • GitOps • Observability • DevSecOps

## Interview talking point
I designed the repository as a production-style platform rather than a single deployment demo. Infrastructure is modularized with Terraform, application delivery follows GitOps principles, CI validates infrastructure and workloads before changes are accepted, and reliability controls such as health checks, autoscaling, disruption budgets, SLOs and runbooks are built into the design. The AWS implementation is the deeper reference path, and the Azure AKS reference demonstrates how the same platform principles translate across cloud environments.
